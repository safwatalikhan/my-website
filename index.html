Research

My work moves automated testing from mechanical to context-aware: tools that understand what is on the screen, reach deeper into an app, and help developers fix what they find. I see these tools as aids that amplify human judgment, not replacements for it.

Mobile UI testing

Getting automated testing past difficult screens

Automated input generation tools often get stuck on "UI tarpits" such as login forms, permission dialogs, and advertisement overlays, and never reach the rest of the app. AURORA pairs a multimodal screen classifier with navigation heuristics so existing tools can recognize and get past these screens. Across 17 popular Android apps it raised code coverage by 19.6%.

ICST 2024 (first author)

AI agents & accessibility

Can AI coding agents fix real accessibility issues?

I lead a study of how well current AI coding agents repair accessibility issues in real web applications. With a team of eight annotators, we open-coded accessibility fixes mined from GitHub pull requests and built a classification of issue types. I then built a reproducible benchmark that runs each application at the exact version where its issue arose, plus a framework that tests proposed fixes automatically, and compared fixes from Claude, Codex, and Qwen agents for correctness and robustness.

Empirical software engineering

How open-source IoT platforms are tested

Smart home platforms combine many devices, protocols, mobile apps, and cloud services, which makes them hard to test. We mined openHAB and Home Assistant and surveyed 80 IoT developers. openHAB has a test ratio of just 0.04 (about 4K test methods for 76K functional methods), and developers rely heavily on unit tests with little integration or manual testing. The study reports 10 findings that point to clear gaps for testing research.

Concept stage

Use-case-aware testing

Code coverage does not show whether testing exercised what users actually do. This project analyzes execution traces (screenshots, interaction logs, and metadata) with information retrieval and LLMs to infer which real use cases an automated tool exercised. The idea was presented at the ICST 2025 Doctoral Symposium; I plan to extend it to regression testing and continuous integration.

Age-related usability in mobile apps

Exploring usability challenges older adults face in mobile apps, with the goal of automated techniques that detect these issues and suggest more usable designs.
